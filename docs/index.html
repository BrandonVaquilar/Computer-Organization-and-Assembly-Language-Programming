01

One image. Three transformations.

Planar RGB buffers move through assembly routines for darkening, sepia, and a custom warm color matrix. Integer arithmetic produces every transformed pixel.

Image processing

The image is an existing coursework asset. Previews are resized for the web; processing runs in ARM assembly.

02

A route through the terrain.

Each step chooses the smallest elevation change in the next column. The cyan cells show the greedy route selected in assembly.

Boundary checks prevent stepping outside the grid. Equal changes prefer east, then northeast, then southeast. The route is not guaranteed to be globally optimal.
